# Change log

## 0.2.0 revised draft, September 19, 2026

Updated the supplied 0.1.0 specification package following the September 19 review. This is a breaking specification revision, not a release of a working FeatureFacts scanner.

### Contract changes

Separated lifecycle, availability, maturity, audience, discovery, intent, publication, and source-observation state. Added unknown and undisclosed states, field-bound evidence, attributed declarations, inference support, explicit assessment completeness, and source locators with hashes and provenance.

Added registry/config envelopes, common definitions, a detector-result contract, and documentation/test association-index schemas. Tightened IDs, locks, dates, uniqueness, references, and scope checks. Replaced quality-like scores and broad-coverage claims with scope-bound association assessments.

Defined persistent approved label selection and name-only overrides, standalone declaration mode, zero-row outcomes, publication-filtered aggregates, safe public metadata, and no public link to the private register. Defined conservative identity matching, explicit reviewed retirement, durable waivers, independent source/projection freshness, full-snapshot diffs, and commit-marker write safety.

### Documentation and workflow

Rewrote all original product, label, build, agent, naming, kickoff, detector, family, skill, and Lite documents to use the revised contract. Added detailed contract, migration, decision, safety/publication, and merge/check references. Moved the first real-repository evaluation earlier and deferred graph scores, viewers, external inference, and other nonessential expansion.

### Examples and validation

Replaced the illustrative real-product label with explicitly synthetic data. Added complete, partial-scan, empty, public, and standalone examples. Added offline schema and semantic validation, mutation regressions, fixture regeneration, and a complete skill-bundle packager.

The validation report distinguishes executed package checks from pending production scanner acceptance. No application code was scanned or tested, no source package was published, and no user repository or website was changed.
